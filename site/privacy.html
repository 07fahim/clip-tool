Privacy policy

The ViralPulse uploader is a personal tool used by its owner. This page explains what it does with Google account data.

What the tool asks for

One permission only: https://www.googleapis.com/auth/youtube.upload. It lets the tool upload videos to the owner’s own YouTube channel. The tool does not read the owner’s videos, comments, subscribers or analytics.

Where the data goes

The login token Google issues is stored on the owner’s own computer, in a file only the owner can reach. It is never sent to a server run by this tool, because the tool has none. The videos are sent from the owner’s computer straight to YouTube.

The tool does not sell, share or advertise with any data.

Removing access

The owner can remove the tool’s access at any time on the Google Account permissions page (myaccount.google.com/permissions). Deleting the token file on the computer also ends access.

This website

This website has no accounts, forms, analytics or cookies. Its text font is loaded from Google Fonts, so Google receives the usual request details, such as your IP address, when a page opens.

Contact

Questions about this page or about data: contact@fahimfaiyaz.dev.

Changes

If this tool changes what it does with Google data, this page will be updated first.
